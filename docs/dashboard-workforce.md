# Workforce dashboard

Retain the existing five rows: Staff, Local Workers, Foreign Workers, Contract Workers and Total Workforce. Show the source reporting month; do not relabel an old report as the current month. Read private workforce rows from the existing overview table (Item, Details): Workforce reporting period (YYYY-MM), Workforce staff, Workforce local workers, Workforce foreign workers, Workforce total workers and Workforce contract workers.

Local and foreign workers are non-staff worker nationality counts and must reconcile with total workers. Total Workforce is staff plus total workers. Harvesters, artisans and leave counts are not added again. Contractor status is a separate employment subcount which can overlap nationality categories, so it is never added a second time. Missing contractor data remains Pending, not zero. Unknown or inconsistent required counts remain Pending.

Only the figures required by the existing dashboard are stored here; required staffing, staffing percentages, nationality breakdown details and Lari/COM figures are outside this panel. No private counts or report documents are bundled in the public repository. Values use the saved estate snapshot and remain available offline. No new APK is created for this source update.
